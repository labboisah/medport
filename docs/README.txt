MediPass System Documentation Pack
===================================
This ZIP contains 12 editable Word documents plus an architecture diagram, implementation checklist, and this README.

The documents are a working product and engineering baseline. They are not a substitute for clinical governance, security review, or Nigerian legal advice. Validate all policies with qualified stakeholders before production use.

Suggested starting point: open 00_MediPass_Documentation_Pack.docx, then review the Product Overview, Functional Requirements, Architecture, and Security/Privacy documents.
